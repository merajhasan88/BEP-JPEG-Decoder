## CPU decoders against the three FPGA decoders on the owner's photos (CPU 2026-10-12, FPGA 2026-10-04)

The CPU decoders were run at full clock on the same 24 files as the Artix-7 board run above: the
owner's 12 phone photos and their 4:2:0 re-encodes (`run_bench.py bench_photos_2026-10-12.json
<files>`, `BENCH_POWER_PROFILE=performance`; first measured on 2026-10-04, `bench_photos_2026-10-04.json`,
re-measured with the review's method: every batch and the versions, settings and input hashes recorded).
The laptop throttles under sustained load: the clock measured during each run is kept in the results
file. The table gives every CPU time rescaled to a steady 3.9 GHz from the run's cycle count (the CPU's
best case). Generated by `bench/photos_report.py`.
